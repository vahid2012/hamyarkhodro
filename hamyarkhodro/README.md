# یدک کش خودرو استان تهران

پروژه کامل سایت امداد خودرو و یدک کش استان تهران — Next.js 14 (App Router) + TypeScript + Tailwind CSS.

## Deploy on Vercel

این پروژه روی دامنه https://www.hamyar-khodro.ir/ دیپلوی می‌شود. همه تنظیمات سئو در کد انجام شده است.

## مشخصات

- شماره تماس: 09032486073 (آقای خسروبیگی)
- مجوز: کانون جهانگردی و اتومبیل‌رانی
- خدمات: امداد خودرو، یدک کش، جرثقیل، خودروبر، باتری به باتری، پنچرگیری، حمل خودرو صفر
- پوشش: ۲۶ شهر استان تهران + صفحه سمنان + صفحه شیراز
- ساعت کار: ۲۴ ساعته ۷ روز هفته

## ساختار

- `/` — صفحه اصلی با ۱۰ بخش
- `/services/[slug]` — ۷ صفحه خدمت
- `/amdad/[slug]` — ۳۶ صفحه شهر (با rewrite)
- `/about` — درباره ما
- `/contact` — تماس با ما
- `/blog` + ۴ مقاله
- `/sitemap.xml` و `/robots.txt` خودکار
- صفحه ۴۰۴ فارسی

## سئو

- Schema JSON-LD: Organization, WebSite, LocalBusiness (AutomotiveBusiness), FAQPage, BreadcrumbList, Article
- عنوان و متا اختصاصی برای هر صفحه
- پاراگراف پاسخ مستقیم (Featured Snippet) در همه صفحات
- Breadcrumb در همه صفحات داخلی
- Sitemap خودکار شامل همه صفحات و شهرها

## شبکه لینک

فایل `BACKLINK_GUIDE.md` راهنمای لینک‌سازی بین سه سایت را دارد.
